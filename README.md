# Delote Beauty — React Website

A modern multi-page beauty salon website rebuilt with React.

The project started as a static HTML/CSS layout and was redesigned into a reusable React application with responsive layouts, animated sections, portfolio filtering, routing, and deployment via GitHub Pages.

## Live Demo

https://terentakula.github.io/delote-beauty-react/

## Features

- Multi-page React application
- Responsive layout
- Modern dark luxury visual style
- Smooth reveal animations on scroll
- Animated service cards
- Portfolio filtering by category
- Reusable React components
- React Router navigation
- Dedicated pages for:
  - Masters
  - Cosmetics
  - Promotions
  - Reviews
  - Contacts
- Smooth scrolling between sections
- GitHub Pages deployment
- Automatic deployment with GitHub Actions

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- CSS
- GitHub Actions
- GitHub Pages
